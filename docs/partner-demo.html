The boundary

What exists now—and what does not.

The automatic-correction work is a prototype plan. It must earn its way into the product through private evidence; having tools to compare approaches is not proof that any approach works.

Available today

One reviewable correction path

  • Editable Original and separate Prepared text
  • Conservative and Smart modes
  • Smart uses one correction method
  • Meaning-bearing Smart repairs can be inspected
  • Explicit Outgoing choice and fail-open Original

Planned prototype

Automatic choice among several methods

  • Compare several correction methods fairly
  • Let Smart choose a method for each case
  • Count wrong choices, failures, and cases where correction cannot help
  • Keep every proposed repair reviewable
  • Integrate only a winner that meets success rules agreed before final results

Planned prototype

Smart should choose carefully, not merely guess harder.

The prototype will test Smart as a whole. One promising correction method is not enough if Smart chooses it for the wrong text.

Compare

Try several methods

Test different ways of correcting text—and useful combinations—on the same qualifying examples.

Choose

Choose inside Smart

Compare always using one method, trying methods in a set order, and choosing based on each piece of text.

Protect

Fail open to Original

If correction fails, takes too long, cannot help, or looks unsafe, usable Original text must remain available.

Prove

Require private evidence

No approach reaches the product unless private examples set aside in advance meet success rules agreed before final results.
