# Issue Tracker

Actionable work for this repository is tracked as GitHub Issues in the private
`dmclark/sayloom` repository.

## Workflow

- Create actionable work as GitHub Issues in the private `dmclark/sayloom`
  repository.
- Use the private user-owned **Sayloom** Project for Status, Priority, and
  Outcome. Use repository labels only for routing signals.
- Keep durable current facts and processes in canonical repository documents
  and qualifying consequential decisions in ADRs.
- Treat Mandrel project `voiceitt-bridge` as unchanged, read-only provenance.
  Never create or update Sayloom records there.
- Do not dual-write work or durable knowledge to Mandrel.
