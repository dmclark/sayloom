# Issue Tracker

Issues for this repository are Mandrel project tasks in the active `voiceitt-bridge` project.

## Workflow

- Create work items as Mandrel tasks with a concise title and enough context to act on them.
- List, inspect, and update tasks through Mandrel's project task operations.
- Use Mandrel task status, priority, assignment, and progress fields to manage work.
- Confirm that `voiceitt-bridge` is the active Mandrel project before reading or writing tasks.

This repository does not use GitHub Issues as its issue tracker.
